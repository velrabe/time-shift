# Быстрый старт

## Минимальные требования

1. Современный браузер с поддержкой ES6+
2. Локальный веб-сервер (для работы с аудио файлами)

## Запуск

### Вариант 1: Простой HTTP сервер (Python)

```bash
# Python 3
python3 -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

Затем откройте: http://localhost:8000

### Вариант 2: Node.js (http-server)

```bash
npx http-server -p 8000
```

### Вариант 3: VS Code Live Server

Установите расширение "Live Server" и откройте `index.html`

## Первый запуск

1. Добавьте аудио файл в папку `audio/` (см. `audio/README.md`)
2. Откройте игру в браузере
3. Игра запустится автоматически с обратным отсчетом

## Тестирование без аудио

Игра будет работать без аудио файла, но без музыки. Просто откройте `index.html` - все остальное работает.

## Управление

- **Кнопки**: Клик по кнопкам для сдвига таймера
- **Клавиши 1-4**: Быстрый выбор кнопок
- **Escape/Space**: Пауза
- **Перки**: Правый верхний угол

## Отладка

Откройте консоль браузера (F12) для просмотра логов и ошибок.
