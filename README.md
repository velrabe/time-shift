# TimeShift

Бесконечная реакционная игра про контроль потока времени.

## Описание

TimeShift — это игра, где игрок управляет таймером, сдвигая его вперед или назад ограниченными действиями, чтобы не допустить попадания опасных чисел в центр экрана.

## Особенности

- **Экспоненциальное ускорение**: Скорость таймера плавно увеличивается по мере прогресса
- **Процедурная генерация**: Опасные числа генерируются процедурно с гарантией решения
- **Система перков**: Continue и Inversion для расширения геймплея
- **Динамическая музыка**: Музыка ускоряется синхронно с таймером
- **Сохранение прогресса**: Локальные снапшоты и синхронизация с GamePush
- **Адаптивный дизайн**: Работает на десктопе и мобильных устройствах

## Установка

1. Клонируйте репозиторий или скачайте файлы
2. Аудио файл `audio/1.mp3` уже настроен (или измените путь в `js/audio.js`)
3. Откройте `index.html` в браузере или запустите локальный сервер

## Управление

- **Кнопки управления**: Клик по кнопкам для сдвига таймера
- **Горячие клавиши**: 1, 2, 3, 4 для быстрого выбора кнопок
- **Пауза**: Escape или Space, или кнопка ⏸
- **Перки**: Клик по кнопкам перков в правом верхнем углу

## Настройка GamePush

Игра использует GamePush для сохранения рекордов. SDK загружается автоматически из HTML.

Если нужно изменить параметры:
- Откройте `index.html`
- Найдите скрипт GamePush и измените `projectId` и `publicToken`

## Разработка

### Основные системы

1. **Timer**: Управляет таймером и вычисляет скорость по экспоненциальной формуле
2. **Director**: Генерирует опасные окна и кнопки управления
3. **PerkSystem**: Управляет перками (Continue, Inversion)
4. **AudioSystem**: Контролирует воспроизведение музыки с динамической скоростью
5. **Renderer**: Отвечает за отрисовку всех элементов игры

### События

Игра использует Event Bus для коммуникации между системами:

- `TICK_STEP` - шаг таймера
- `SHIFT_USED` - использование сдвига
- `BUTTON_CLICKED` - клик по кнопке
- `DANGER_PASSED` - прохождение опасного окна
- `DEATH` - поражение
- `PAUSE` / `RESUME` - пауза/резюм
- `PERK_ACTIVATED` - активация перка

### Балансировка

Основные параметры для настройки:

- `timer.k` (в `timer.js`): Коэффициент ускорения (по умолчанию 0.004)
- `director.calculateWindowLength()`: Длина опасных окон
- `director.scheduleNextThreat()`: Интервалы между угрозами
- `perks.requiredStreak`: Требуемый стрик для перков
