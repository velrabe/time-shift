# Audio Files

Поместите аудио файлы в эту папку.

## Требования

- **Формат**: MP3, WAV или OGG
- **Файл**: `main.mp3` (или измените путь в `js/audio.js`)

## Рекомендации

- Используйте треки с четким ритмом для лучшей синхронизации с ускорением
- Длительность: 2-5 минут (будет зациклен)
- Битрейт: 128-192 kbps для баланса качества и размера

## Настройка

Если хотите использовать другой файл или формат, откройте `js/audio.js` и измените:

```javascript
this.tracks = [
    {
        id: 'main',
        url: 'audio/your-file.mp3', // измените здесь
        bpm: 120
    }
];
```
